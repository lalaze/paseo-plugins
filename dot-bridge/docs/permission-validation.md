# Paseo 原生授权接入验收

## 权限边界与恢复修复（2026-10-13，仓库验证）

- 文件授权绑定操作 UUID、路径、修改前和修改后的 SHA-256；不能借修改授权删除文件、替换内容或执行第二次操作。附件授权绑定 UUID、名称、MIME、大小和完整内容 SHA-256；分块上传在完成发布后才消费授权。完全相同的重试返回原回执。
- 拒绝、失效和已消费的访问不会因普通追问或新轮次恢复默认放行；必须重新提交明确范围并由本地用户批准。文件、目录及附件读取均执行相关权限检查，附件两种读取入口共享限制。
- 审核补修：只读或外部操作授权不能放行文件修改、普通上传或分块上传，追加普通消息仍需明确写入授权；附件别名只匹配 `read_dot_attachment` 与 `read_dot_attachment_chunk`，外部工具名 `attachment-read` 不会覆盖拒绝记录或获得读取权限。两项回归测试在修复前失败、修复后通过，并验证重新明确授权后可正常执行。
- 界面区分当前有效、历史已替代、失效、已使用与平台阻塞；读取明确为当前消息下的重复读取范围，写入明确为一次绑定操作。平台审批仍由 Dot 回报，不由 Paseo 按钮代替。
- 增加本地终止入口，要求先请求停止。释放已领取任务占用的名额，禁止旧轮次工作区访问和上传，保留远端停止尚未确认的事实；迟到成果只能进入历史，不能重新激活已终止轮次。
- 监听失败显示实际错误并按 2.5–30 秒退避重试；重复检查不会并发启动服务。真实本机端口占用/释放测试验证恢复。
- 存储升级为 v10；原始 v9 字节备份为 `state.v9.json`，旧 pending/approved 授权变为 expired，拒绝记录保留。升级后需刷新 ChatGPT 工具并更新连接说明。

自动化覆盖位于 `permissions.test.ts`、`attachment-transfers.test.ts` 和 `listener.test.ts`。`npm run check` 通过：199 项测试、TypeScript 类型检查和 esbuild 构建；当前环境未使用 Paseo 宿主编译器验证导入边界。本节仅为仓库及隔离测试验证；尚未部署本次修改，也未进行真实 ChatGPT 连接或设备界面验收。下方保留上一版本的实机记录。

## 初版接入（2026-10-12）

用户需要在 Paseo 看见并确认 Dot 的授权请求。已接入原生 provider permission 协议与 Dot tasks 详情按钮，新增 `request_dot_permission`、`report_dot_permission_blocked` 两个 MCP 工具，没有远端批准工具。

请求和决定持久化到 v9 状态。允许或拒绝会原子写入带范围的用户消息及唤醒事件。停止、新输入或轮次结束后，旧 pending 请求失效；重复决定幂等，冲突决定拒绝。当前 pending、denied、platform-blocked 请求禁止 Bridge 写文件和上传；当前批准仅覆盖指定工具及文件路径/附件名，不代表其他工具也获授权。

Paseo 的授权不能替代 ChatGPT 平台审批。平台仍拒绝时，Dot 报告实际原因，Paseo 显示等待状态及 Your dot 入口。用户在那里完成具体确认后回到原会话；不得伪造平台接受。如果回报工具本身被平台取消，Bridge 无法获知未送达的失败，Dot 必须在主页如实说明。
